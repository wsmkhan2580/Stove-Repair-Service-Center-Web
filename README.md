Stove Repair Service Center 🔧🔥

📌 Overview
This is a Stove Repair Service Center website built with HTML, CSS, and JavaScript.  
It provides information about services, contact details, and tools for stove repair.  
The project is deployed live on Vercel.

---

🚀 Features
- Responsive design for desktop and mobile  
- Service details page with clear layout  
- Contact form for customer inquiries  
- Tools page showcasing repair equipment  
- Clean folder structure with external CSS and HTML files  
- Deployed live on Vercel for easy access  

---
